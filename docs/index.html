手机主屏幕

把申购日程放到手机桌面

安装后可像应用一样打开，手机无需运行 Python。

iPhone / iPad

请用 Safari 打开本页，点“分享”按钮，选择“添加到主屏幕”，再点“添加”。

Android

请用 Chrome 或 Edge 打开本页，从浏览器菜单选择“安装应用”或“添加到主屏幕”。支持自动安装提示时，可直接点击下方按钮。

微信内置浏览器请先选择“在浏览器中打开”。首次联网打开后可缓存页面；离线日程可能过时，须核对更新时间。安装不会开启后台推送。
